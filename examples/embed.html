Embedding scenes

One script tag defines <qubibyte-scene>. The scene loads when it scrolls into view and runs in a sandboxed worker, never in the page.

<script type="module" src="../src/embed/qubibyte-scene.js"></script>
<qubibyte-scene src="00-first-scene.js" autoplay loop controls></qubibyte-scene>

Driving it from script

The element exposes play(), pause(), seek(seconds), currentTime, and duration, and dispatches ready, play, pause, timeupdate, and ended. With reduced motion requested, it shows the last frame and does not autoplay.
